# 黑曜石流体毛玻璃 · 个人空间模板

采用 **高级黑曜石暗黑（无蓝调）+ 透明流体毛玻璃材质** 打造的纯净个人网站模板。

## 目录结构（共 6 项，不含友链）
- `首页 (#home)`：100vh 居中开屏 + 流体毛玻璃空间入口
- `博客 (#blog)`：支持标签筛选、关键词搜索与 Markdown 阅读弹窗
- `随笔 (#essays)`：支持分类筛选、心情标签与配图灯箱
- `画廊 (#gallery)`：支持分类与全屏键盘灯箱
- `留言 (#guestbook)`：流体毛玻璃留言板（本地可即时体验，上线后可接入免费 Giscus / Twikoo）
- `关于 (#about)`：自由填写个人与建站介绍（非简历）

## 使用方式
1. 在 `data.js` 中按注释填入你的昵称、文章、随笔、画廊照片与关于介绍。
2. 本地预览：`python3 -m http.server 8766`，访问 `http://127.0.0.1:8766`。
3. 免费上线：拖入 Cloudflare Pages（Direct Upload）即可永久免费发布。
